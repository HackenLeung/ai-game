# 魔塔 · 五十层（h5mota《50层魔塔》复刻）

纯原生 HTML / CSS / JavaScript，无构建步骤、无外部依赖。玩法按 [h5mota](https://h5mota.com/games/51/)《50层魔塔》Ver 3.0 复刻：相同的地图、怪物数值、道具、商店、事件与结局；视觉沿用本仓库的像素地牢风格。

## 玩法

- 51 个 13×13 的房间（第 0 层地下室 + 第 1–50 层），地图逐格照原塔还原：黄/蓝/红三色门、机关门、铁门、暗墙、空气墙、熔岩、箭头、楼梯、血网位置都与原版一致。
- 战斗完全确定：先手永在勇士这边，回合数、每回合伤害、战后损失都能事先算清。**敌人脚下直接标出打它的损血**；破不了防与必死的格子会被拦下（"防御太高 / 进入这里会死亡"），不会让你白送。
- 21 种怪物特殊属性：先攻、魔攻、坚固、2/3/N 连击、破甲、反击、净化、模仿、吸血、中毒、衰弱、诅咒、领域、夹击、仇恨、阻击、自爆、无敌、退化、固伤、重生。手册（`X`）给出每只怪的血攻防、属性、临界攻击与"1 点防御能少掉多少血"。
- 道具与商店：血瓶/宝石/钥匙、圣水、万能药水、解药、镐、炸弹、圣锤、冰魔法（雪花，用来冻结熔岩）、跳跃靴、魔杖（楼传）、幸运金币、十字架、屠龙匕、圣剑/圣盾、神圣盾；祭坛按购买次数涨价（`20+10×(n+1)×n` 金币，生命 +100×(n+1)、攻击 +2×区数、防御 +4×区数），商人卖钥匙，小偷开路，老人指路，公主与封印魔王都照原事件。
- 两种规则：**特性版**（对话穿墙、圣水复活、偷雪花）与**纯净版**；结局分 TE / NE，通关给一份成绩单。
  - 在 50 层与变成魔王的「小偷」对话过，再打倒 49 层魔王即为 TE，否则是 NE；标题与成绩单会写出「特性版 / 纯净版 · TE / NE」。
  - 3 层魔王会剥掉「魔法免疫」并把勇者打回 400/10/10，从那一刻起「阻激夹域」（阻击/夹击/领域）才开始生效，直到拿到神圣盾。
- 自动存档（每次行动）、进入楼层记一次入口、撤销最多 24 步、存档导出与导入。

## 操作

| 操作 | 说明 |
| --- | --- |
| 方向键 / W A D | 走一格，撞向敌人即开战（向下用 ↓，S 是存档） |
| 点击地图 | 点一处能走到的格子，勇士沿最短路自己走过去：钥匙够就顺手开门、顺路捡药水宝石；碰到怪物、楼梯或剧情对话就停下（点怪物/门/NPC 会走到它旁边再撞） |
| 点击身边一格 | 使用选中的道具（镐 / 炸弹 / 圣锤 / 冰魔法 / 跳跃靴） |
| 鼠标悬停 | 格子说明：血瓶 / 宝石这一层加多少，怪物的生命攻击防御与预计损血（触屏没有悬停，点一下就是走过去） |
| 空格 / 回车 | 继续对话、确认选项 |
| `X` | 怪物手册 |
| `G` | 楼传（去过的楼层） |
| `S` / `L` | 快速存档 / 存档面板 |
| `H` / `?` | 游戏帮助 |
| `1` / `2` / `3` | 快捷道具 |
| `Ctrl+Z` | 撤销上一步 |
| `Esc` | 取消道具或关闭弹层 |

手机上提供方向键与道具按钮。

## 文件

- `data.js`：游戏总配置（初始勇者、数值表、特殊属性文案），并把 `h5data/` 的五张表合并成一份数据。
- `h5data/`：由 `tools/port-h5mota.cjs` 从 h5mota 原工程生成的 `tiles / enemys / items / floors / commonEvents`。
- `rules.js`：纯规则层（无 DOM、无存储）：特殊属性、战斗结算、临界攻击、减伤、道具效果、商店价格。
- `engine.js`：状态机：地图、移动、触发、阻激夹域、战斗、道具、商店、存档、撤销。
- `events.js`：h5mota 事件脚本解释器（`if/switch/while/for/break/exit/setValue/choices/hide/show/setBlock/openDoor/closeDoor/setEnemy/battle/changeFloor/win/insert/moveHero/tip/playSound`）。
- `view.js` / `sprites.js` / `styles.css` / `index.html`：界面、像素贴图、样式与页面结构。
- `route.js`：点地图自动走路的寻路核心（带钥匙状态的 Dijkstra；楼梯只当终点、门算钥匙、陷阱绕开）。
- `app.js`：输入、渲染、弹层、存档面板、走路节奏与引擎接线。
- `tools/port-h5mota.cjs`：从 `h5mota` 工程（`.cache/h5mota51`）重新生成 `h5data/` 的移植脚本；含少量数据兼容修正（如 10 层骷髅队长的战后剧情坐标）。
- `tests/`：`rules.test.cjs`（规则）、`data.test.cjs`（数据自洽）、`engine.test.cjs`（引擎行为）、`stairs.test.cjs`（每层楼梯的上/下方向与落点）、`route.test.cjs`（自动走路寻路）、`play.cjs`（结构通关）、`smoke.cjs`（浏览器）。

## 已知差异

- 原塔的部分「录像 / 自动寻路 / 楼层瞬移 / 自动战斗开关」辅助功能不移植；不影响玩法与数值。
- 图块渲染沿用本仓库像素风格，不复用原塔素材；隐形墙、机关标识等按原工程的显示规则处理（隐形墙不可见、不可破墙显示为黄墙）。
- 第 0 层（地下室）与 20 个未上图的占位怪物（`hp=0`）按原数据保留，正常流程不会遇到。
- 楼传按原塔语义：保留当前坐标，`canFlyTo:false` 的楼层不可选；关闭「额外功能」后必须站在楼梯上才能使用。
