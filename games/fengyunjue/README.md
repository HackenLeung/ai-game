# 逸剑风云决 · 问剑长歌

一个可离线游玩的原创像素武侠同人 HTML 游戏。三章主线现有 **49 段任务、9 张地图、19 场主线交锋**，另有九道悬赏、十二层剑冢、章节重游和三项支线。画面、音乐与环境音由浏览器生成，没有运行依赖、外部字体或在线素材。

## 开始游玩

保留 `index.html`、`style.css`、`expansion.js`、`story.js`、`combat.js`、`rules.js`、`feedback.js`、`audio.js`、`game.js` 在同一文件夹，直接用 Edge、Chrome 或 Firefox 打开 `index.html` 即可。也可运行：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4173/?v=4.3>。右侧「当前指引」会寻路、切换地图，并在战斗结束后接续下一目标。

高坡与浅滩、火阵与正道会出现不同敌阵。连灯机关会同时翻转本格与四邻，需要将九灯全部点亮；可以重置或索取一步提示。查访所得的证言可在江湖志查看。

## 战斗与修行

每回合先移动，再攻击、治疗、援救、用药或守势一次。每种流派的移动格数不同，详情见「修行」。人物遮住地格时，先选「移步」，再点击空格。

- **架势与积势**：普攻积累剑势；破岳剑与清风掠影会消耗剑势增强伤害。击空敌人的黄色架势条可打断蓄力，使其失去一次行动，并在下一次追击时承受更多伤害。
- **敌人各有作用**：药师每两个回合治疗伤者；毒师能叠加慢毒；护阵柱使首领减伤 65%。盾卫可用破岳剑应对，首领半血变招，部分首领还会召援。
- **先看胜利条件**：护送对象倒下也会败北；守夜需要撑满回合；哨台需要连续站稳；突围需要走到金色出口。红格是下一轮重击的范围，橙色火地会在本轮结束时喷发。
- **补给有限**：金疮药、玉露丸、养气丹、解毒散与食物共用每战用药次数，服用后还需间隔一回合。内功可解一层毒，解毒散能清除全部中毒。
- **内息与调息**：基础每回合回复 4 真气；守势回复 12 真气并减伤 60%。凝神归元消耗 22 真气，使用后需间隔两回合；剑归沧海消耗 36 真气，需间隔三回合。破岳剑、飞花毒刃、援救需间隔一回合。
- **流派和心诀**：中正均衡；疾风擅走位与积势；磐石擅防守反击；归元擅内息与治疗。第三章解锁摧坚、流芳、守心三门心诀。战斗外可免费切换。
- **装备和成长**：兵刃、护具、佩饰需要在行囊中手动装备。佩饰有明确长短处，一次佩戴一件；可从悬赏取得，也可用侠义令、玄铁和铜钱打造。每柄剑可淬炼三次。
- **修习取舍**：招式最高五重，提升一重依次花费 1、2、3、4 点悟性。提高攻击招式每重增加 4 基础伤害（毒刃直伤按四成计算）和 2 破势；内功每重多恢复 8 气血。升级与参悟剑谱可获得悟性。
- **同伴**：陆青霜隔回合射箭援护，莫问隔回合治疗并为每轮首次受击提供减伤。一次邀请一位，照心独战时同伴不参与。

默认难度为「险境」。初次上手可选「游侠」；熟悉机制后可选「宗师」。三种难度分别有 4、3、2 次基础用药机会，并改变敌方气血与攻击。

## 通关后的历练

「历练」可随时打开。击败青竹径山匪后开放悬赏与剑冢，平康擂台可重复切磋。

- **九道悬赏**依次解锁，敌人会随境界增强，每道只领取一次报酬。可得侠义令、玄铁、铜钱与特色佩饰；不会推进或重置主线。
- **十二层剑冢**包含破盾、施毒、守渡、占点、试剑、突围、护送、火阵与破柱终战。进入时恢复状态，此后层间延续气血与真气，每胜一层选择一项祝福，同一祝福最多三重。全程只有一次篝火，可恢复六成气血与真气。升级在剑冢中只提高上限，不会补满资源。层间不能服药或换装，药物和内功留在交锋中使用。已选祝福、当前层和资源会保存，重开页面可继续。
- **失败或退出剑冢**会结束本次挑战，已领报酬和最高层记录保留；下次从第一层开始。完整登顶建议八重以上。
- **章节重游**在主线完结后开放。保留境界、装备、招式、同伴及悬赏记录，从所选章节开始重新经历后续故事，敌人随境界增强。确认后才会重置这些主线阶段，并自动备份重游前的存档。
- **三项支线**是鲜鲤暖汤、故人玉扣、失散镖货。九地还可回访、寻箱、采矿、垂钓与锻造。

## 操作

| 操作 | 快捷键 |
| --- | --- |
| 行走 / 交互 | WASD 或方向键 / E |
| 行囊 / 修行 / 江湖志 | B / K / J |
| 舆图 / 同伴 / 历练 | M / P / T |
| 普攻 / 清风掠影 / 凝神归元 | 1 / 2 / 3 |
| 金疮药 / 守势 / 绝学 | 4 / 5 / 6 |
| 破岳剑 / 飞花毒刃 / 援救 | 7 / 8 / 9 |
| 移步模式 / 游玩指南 / 关闭面板 | 0 / ? / Esc |

所有操作也可点击按钮，手机端有方向控制与两排战斗按钮。战斗上方持续显示气血、真气、用药次数和胜利目标。

出招会显示剑光、命中火花与伤害，受击时人物短暂后仰，破势与首领蓄力有独立提示。用药显示实际气血或真气恢复量、清毒层数和剩余数量；换装会高亮当前装备，并展示属性增减。最后一击会先播放完短暂反馈，再进行一次战斗结算。

系统设置「减少动态效果」时保留数字和结果提示，关闭出手位移、闪亮与粒子动画。

## 场景音乐与音效

右上角声音按钮同时控制音乐、环境音与交互音效，初始保持静音，点击后开启。悬停按钮可查看当前曲名与声景。全部使用 Web Audio 合成琴、琵琶、箫、钟磬和打击乐音色，可直接离线播放。

| 地点 | 曲名 | 声景 |
| --- | --- | --- |
| 梧桐村 | 梧桐烟雨 | 古琴、溪水、山鸟 |
| 芦苇渡 | 一苇渡江 | 箫声、水音、水鸟 |
| 青竹径 | 竹影行歌 | 笛音、拨弦、竹叶 |
| 平康城 | 灯市小调 | 轻快琵琶、街市杂声、茶盏 |
| 废窑密道 | 残窑暗流 | 低弦、石室滴水回响 |
| 黑风寨 | 黑风夜行 | 沉弦、寨鼓、山风篝火 |
| 武当山 | 云外问道 | 琴箫、松风、悠远晨钟 |
| 问心古道 | 雪阶照心 | 泛音、松雪风声、石磬 |
| 落霞谷 | 落霞听雷 | 长箫、峡风、远雷 |

普通交锋、友好切磋、首领战、最终决战、剑冢交锋与层间休整另有六套编曲；首领狂暴时打击乐更紧张。旋律包含问答乐句、低音伴奏与间歇变化，环境音在两侧适度分布。

地图与战斗切换会淡入淡出，出招和结算时背景会短暂降低音量。普攻、横扫、破岳剑、毒刃、绝学、格挡和受击分别发声；吃药、回气、清毒、内功恢复，以及拔剑装备、穿甲、佩玉也有不同音色。采药、挖矿、垂钓、开箱与机关补有声音反馈。

静音会清理已排队音符与回声；切到后台暂停，返回后按当前场景重新起奏。快速开关或切换地图仍只使用一个音频上下文与调度器，并限制同时发声数量。

## 存档

继续使用旧键 `wandering-sword-v1`，存档结构升级为第 3 版，旧版序章和原三章版会按任务身份自动衔接，保留等级、装备、物品及已完成章节。旧版已通关的存档可直接游玩新悬赏、剑冢或选择章节重游。升级时另存一份原存档。

任务、探索、层间进度自动保存；交锋以开战前与结算后为存档节点。失利恢复气血真气，保留任务、装备与剩余物品；主动撤退会保留药品与真气消耗。「游玩指南」可导出、导入存档或恢复重游备份；全新开局与重游均需要在游戏中确认。

续玩请使用原浏览器与原地址。不同浏览器、隐私窗口、直接打开 HTML、`localhost` 与 `127.0.0.1` 的存档可能不同；更换地址前可导出存档。清除浏览器站点数据会清除本地进度。

## 开发与验证

运行游戏无需安装依赖。规则验证需要 Node.js：

```sh
node verify.cjs
node test-strategy.cjs
```

规则检查覆盖章节与地图数据、存档迁移、任务防重复、武学成长、战斗目标、破势、中毒、同伴、悬赏及剑冢。策略试跑使用合法动作走完 19 场主线战斗，不改变胜负、敌方气血或战斗资源。

有 Playwright 与浏览器时，还可运行真实界面验证：

```sh
node verify-browser.cjs
node verify-feedback.cjs
node verify-audio.cjs
```

默认使用独立的 Edge 浏览器环境和本地 HTML，不读取玩家正在使用的浏览器存档。依次验证完整主线、全部悬赏、十二层剑冢、支线与装备、导出导入、章节重游、手机战斗、旧存档、败退与两条替代路线。

可用 `--campaign-only`、`--challenges-only`、`--extras-only`、`--mobile-only`、`--legacy-only`、`--branches-only`、`--expedition-only` 运行对应部分。`verify-stuck.cjs` 运行原先「战后没有后续任务」的回归。`BROWSER_PATH` 可指定浏览器，`PLAYWRIGHT_MODULE` 指定 Playwright，`GAME_URL` 指定本地预览地址，`GAME_SCREENSHOT_DIR` 指定截图与验证存档目录。

`verify-feedback.cjs` 使用独立存档检查装备增减属性、最后一份药、满血拒绝用药、气血与真气区分、音效开关、真实战斗与单次胜利结算，以及手机和减少动态效果模式。

`verify-audio.cjs` 检查九图切换、不同交锋与剑冢休整、快速开关、静音清理、后台与页面恢复、手机点击及音频启动失败恢复；另用浏览器真实 `OfflineAudioContext` 渲染十五套编曲，检查有效音频、声道差异、峰值、持续发声、不同乐句与密集音效下的资源上限。验证存档使用独立浏览器环境。

`story.js` 保存原有任务身份；`expansion.js` 以任务身份插入新增章节内容并映射旧阶段，避免旧存档跳错任务。`rules.js` 管理角色、存档和历练进度；`combat.js` 管理回合战斗；`game.js` 管理界面、地图与像素绘制；`feedback.js` 负责动效与提示；`audio.js` 负责场景编曲、合成音效、混音和声音生命周期。`test-strategy.cjs` 只供验证使用，不会加载进游戏。
