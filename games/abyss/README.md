# 深渊回响 · ABYSS ECHO

在浏览器里游玩的单人牌组构筑冒险（roguelike deckbuilder）：选择一名角色，从回响航母一路攀升到回响之源，穿越 **12 个章节、共 180 层** 地图，用不断扩大的牌组和遗物活下来。

## 玩法

- **每回合**：获得 3 点能量，抽 5 张牌。手牌消耗能量打出，回合结束时未使用的牌进入弃牌堆。
- **格挡**：获得的格挡会在**下个回合开始时清空**，所以防御要放在真正会被攻击的那一回合。
- **意图**：敌人头顶显示下一次行动与预计伤害，先看清再决定进攻还是防守。
- **状态**：`力量` 提高攻击伤害，`迅捷` 提高格挡，`敏锐` 提高攻击伤害且不会自然消失；`易伤` 使受到的攻击伤害 +50%，`虚弱` 使其造成伤害 −25%，`中毒` 在回合开始按层数失去生命，`灼烧` 在回合结束结算。
- **地图**：每章固定 15 层，依次包含普通战斗、精英、未知事件、维修站、补给舱、黑市与首领。选择节点后不能回头。
- **章节成长**：每通过一章，核心的生命上限提升、回复部分生命，并且每两章提升 1 点能量上限；深层章节进入战斗时自带少量格挡。
- **奖励**：战斗后可以单独领取金币、遗物、药水与三选一卡牌，也可以直接跳过。金币、卡牌质量与休息恢复量都会随章节提高。
- **反馈**：出牌会飞向目标并弹出伤害数字，敌人按顺序逐个行动（带蓄力高亮与阶段提示），受击会震动与闪白。开启系统的「减少动态效果」后保留伤害数字与日志，去掉位移与震屏。

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标 / 触屏 | 点击手牌出牌；多敌人时再点击一名敌人确认目标 |
| `E` | 结束回合 |
| `1`–`3` | 使用对应药水 |
| `D` / `R` | 牌组 / 图鉴 |
| `?` | 玩法说明 |
| `Esc` | 关闭弹窗 |

## 存档

存档键为 `abyss-echo-save-v1`，保存在浏览器本地。每次选择节点、结束战斗、商店交易后自动保存。右上角「存档与设置」可以导出存档文本、导入存档或重新攀登；重新攀登会覆盖当前进度，导入前请确认内容。

## 代码结构

```text
games/abyss/
├─ index.html    页面结构与图标定义
├─ styles.css    界面样式与响应式布局
├─ data.js       卡牌、状态、角色与奖励池（纯数据）
├─ enemies.js    12 章敌人、精英与首领的行动表（纯数据）
├─ world.js      遗物、药水、章节、事件与地图生成（纯数据）
├─ engine.js     战斗与推进引擎：伤害、状态、意图、奖励、章节成长、存档（无 DOM 依赖）
├─ ui.js         DOM 渲染片段
├─ fx.js         战斗动效层：伤害数字、震屏、飞牌与阶段提示
├─ app.js        交互绑定与流程编排
└─ tests/
   └─ engine.test.cjs  规则验证与 12 章自动试跑
```

规则逻辑与界面完全分离：`data.js`、`enemies.js`、`world.js`、`engine.js` 可以在 Node 中直接 `require`，测试不需要浏览器。

## 测试

```sh
node --test games/abyss/tests/engine.test.cjs   # 在本目录中：node --test tests/engine.test.cjs
```

覆盖内容包括：起始牌组与地图结构、12 章敌人完整性、伤害公式（格挡 / 易伤 / 虚弱 / 力量）、中毒结算时机、能量与消耗、X 费卡、战斗奖励、遗物触发器、营火与升级、商店折扣、事件结算、存档序列化与损坏存档回退、章节成长、荆棘与狂暴、敌人回合逐个推进、战斗事件记录，以及一次完整的 12 章自动试跑。

浏览器验证在仓库根目录运行 `npm run test:browser`。
