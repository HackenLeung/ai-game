# 余烬 · 荒野生存手记

一个受《饥荒》生存机制启发的原创中文文字游戏。所有画面均为 HTML、CSS 和原创 SVG，没有在线资源、账号或运行依赖。

直接双击 **index.html** 即可游玩。请把 `styles.css`、`game.js`、`effects.js`、`app.js` 和 HTML 保存在同一个文件夹。

- 六个区域：营地、松林、草地、石坡、湿地、遗迹。
- 采集、制作、烹饪、工具耐久、天气、体温、昼夜、随机奇遇。
- 生命、饱食和理智共同影响生存；行动才会推进时间。
- 在营地建造归途信标，熬过七个夜晚并返回营地，即可通关；之后可继续自由生存。
- 每次行动自动存档，右上角可导出、导入或开始新的旅程。
- 支持手机布局、键盘快捷操作，以及可选的行动音效。
- 炭笔森林、旧纸手记与焦木行囊；可以直接点击场景中的篝火、帐篷和采集目标。
- 采集物品飞入行囊，生命与饱食变化浮字，添柴火星、飘叶、雨幕、受伤提示及昼夜转场。

动效不会推进游戏时间。右上角「存档与设置」可以关闭动效和音效，也会遵循系统的减少动态效果设置；页面隐藏、营地滚出屏幕或窗口弹出时，环境粒子会暂停。

开局先制作石斧。去草地准备食物，去松林准备木材。夜间外出要点燃随身火把，营地的篝火无法保护路上的你。更多规则可查看右上角「生存手册」。

自动存档属于当前浏览器与打开地址；清理浏览器数据、移动游戏目录、更换浏览器，或在直接打开 HTML 与本地预览之间切换前，建议导出备份。

## 本地预览与验证

有 Node.js 18 或更新版本时，不用安装依赖即可运行：

```sh
npm start
npm test
```

预览地址为 `http://127.0.0.1:4173`。也可以继续直接打开 HTML。

可选浏览器验证：安装 Playwright 和 Chromium 后执行 `npm run test:browser`，动效与连续操作验证使用 `npm run test:effects`。已有 Playwright 的环境可使用 `EMBER_PLAYWRIGHT_PATH` 指定包路径，`EMBER_BROWSER_PATH` 指定浏览器可执行文件。浏览器验证使用隔离的临时浏览器上下文，不会改动你正在游玩的存档。

规则在 `game.js`，交互在 `app.js`，动效在 `effects.js`，画面与样式在 `index.html` 和 `styles.css`。
