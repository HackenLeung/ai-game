# 静雷 · 数字雷区

现代简约风格的扫雷小游戏，纯原生 HTML / CSS / JavaScript，无外部依赖。

## 玩法

- 翻开所有安全格即胜利；数字表示周围八格的地雷数量，空地会自动连锁展开。
- 首次点击会把雷避开点击位置周围的九宫格，因此第一手一定安全。
- 右键或手机长按插旗；在已翻开的数字上双击（或按 `C`）可以快速展开周围格子，前提是周围旗数等于该数字。手机上直接轻点已翻开的数字也会尝试快速展开。
- 初级 9 × 9 / 10 雷、中级 16 × 16 / 40 雷、高级 16 × 30 / 99 雷。
- 自定义棋盘支持 5–30 行、5–40 列，雷数上限为「总格数 − 9」，保证首点安全区。
- 用时与各尺寸最佳成绩自动记录；刷新、返回大厅后可以继续未完成的对局。

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键 / 轻点 | 翻开格子 |
| 右键 / 长按 | 插旗、取消插旗 |
| 双击数字 / 中键 | 周围旗数正确时快速展开（手机上轻点数字） |
| 方向键 | 在棋盘上移动焦点 |
| `Space` / `Enter` | 翻开当前格 |
| `F` | 插旗 |
| `C` | 快速展开 |
| `R` | 开始新局 |

## 文件

- `rules.js`：不依赖 DOM 的规则引擎，负责布雷、翻开、插旗、快速展开、胜负判断与存档序列化。
- `app.js`：界面渲染、计时、自适应棋盘、键盘与触屏交互、本地存档。
- `index.html` / `styles.css`：页面结构与视觉样式。
- `tests/rules.test.cjs`：规则、首点安全、连锁展开、插旗、快速展开、胜负与存档校验。

## 存档

- 对局：`minesweeper-save-v1`
- 成绩：`minesweeper-records-v1`

存档保存在当前浏览器。切换棋盘尺寸或开始新局时，若当前对局仍在进行，会先确认再覆盖；最佳成绩不受影响。

## 验证

```sh
node --test games/minesweeper/tests/rules.test.cjs
npm test
```

浏览器验证可通过根目录的 `npm run test:browser`，或在本地预览后直接打开 `games/minesweeper/index.html`。
