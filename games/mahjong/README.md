# 麻雀学堂 · 广东牌算番、筹码与对局

把广东牌（旧章口径）从「怎么拿牌」教到「这手牌值几番、该收几个筹码」，再坐下来和三家电脑打一局。所有牌面都是矢量绘制的真实麻将牌：万、筒、索、风、箭。

## 功能

| 分区 | 内容 |
| --- | --- |
| 学 · 上手 | 七节课：认牌、开局拿牌、行牌顺序、吃碰杠、胡牌牌型、算番、结算，附术语速查 |
| 拿牌 · 开局 | 分大小 / 相加（两粒或三粒）两种数法，输入骰子点数和座位，算出开门方位、从第几墩开始、跳牌与补花 |
| 算番 · 番种 | 点牌上手，实时拆牌、列番种、算总番；可调起胡、封顶、底分、每番、庄家加半 |
| 筹码 · 结算 | 不算番，直接记筹码：自摸、抓马、公杠、暗杠、放杠，赢家下一把坐庄；可随机试算 |
| 对局 · 四人麻将 | 你坐 0 号位（首局东位），三家电脑；136 张，默认鬼牌红中当万能牌，可切白板 / 发财或无鬼无花；庄家掷骰按点数开门、数墩发牌，摸打碰杠吃胡；中间牌河收四家弃牌，带摸牌来源、打法提示与理牌按钮；按筹码结算，不算番、不抓马 |
| 练 · 胡牌与听牌 | 随机出题：判断 14 张能不能胡，或 13 张听哪些牌，答完显示拆解 |

### 规则口径

- 三番起胡，默认封顶 13 番，可在页面里改。
- 番种：平胡、门前清、自摸、对对胡、混一色、清一色、小/大三元、小/大四喜、字一色、混幺九、绿一色、七对、十三幺、九莲宝灯、杠上开花、海底捞月、抢杠、天胡、地胡、番子、花牌、正花。
- **鬼牌**（红中 / 白板 / 发财可选）：按当前牌桌的常见限制实现——不能碰杠、不能做眼，只能补顺子或刻子，且不计番。
- **花牌**：8 张花，摸到摊出补一张，每张 1 番，正花可另计。
- 结算：自摸三家付、出铳一家付；「底分 + 番数 × 每番」与「底分 × 2 的番数次方」两种算法。

### 筹码口径（不算番）

- 自摸每家 2 个筹码；出铳由放炮那家付 2 个。可在「筹码」页改。
- **抓马**只跟自摸走：有鬼抓 4 张，无鬼抓 6 张；马按**赢家座位**算——
  - 东（庄）：一、五、九 + 东 + 中
  - 南：二、六 + 南 + 发
  - 西：三、七 + 西 + 白
  - 北：四、八 + 北
- 每中一只马，三家各多付 1 个筹码（可改）。
- 杠：公杠（补杠）三家各付 1 个；暗杠三家各付 2 个；放杠只有放杠那家付 3 个。
- 赢家下一把坐庄，座位与马随之顺延；累计筹码按「我 / 下家 / 对家 / 上家」四家记账。
- 这桌没有花，马张数只看有没有鬼。

### 对局口径

- 四人一桌，你固定坐 0 号位（首局东位）。每局由庄家摇骰，骰子规则与「拿牌 · 开局」相同：分大小 / 相加、从下一墩或同一墩开始拿。点数先数人找开门方位，再数墩找起手墩，然后按逆时针发牌。
- 牌墙画成四道墙的示意图：每面 17 墩、每墩上下两层；没摸的牌用大块浅色牌背标出，已经摸走的位置变暗，金框是开门墩，亮色是下一张要摸的墩，浅青色是跳牌留下的尾牌。中间显示「开门：某位第几墩」和「下一摸：某位牌墙第几墩、上层/下层」。
- 每次摸牌都会在牌桌中央弹出播报：谁摸牌、来自哪面墙第几墩、上层还是下层，以及「已入手牌」。你摸到的牌会亮出牌面；电脑摸牌只显示牌背和位置，牌桌动态里也不写牌名，避免偷看。电脑摸牌后会停约 1 秒再出牌，方便一张一张看清流程。
- 发牌：庄家起逆时针每家 4 张（2 墩）× 3 轮；庄家跳牌 2 张（第 1、3 墩上层），其余三家各拿 1 张，所以庄家 14 张、其余 13 张。跳牌剩下 5 张下层牌留到牌墙尾。
- 136 张，无花；默认鬼牌红中，可在对局右上角切换到白板、发财或无鬼无花。鬼牌能补顺子或刻子，**不能碰、不能杠、不能做眼**，也不计番；摸到鬼牌直接留在手里。吃只能吃上家，碰杠不限来源，胡优先于碰杠，碰杠优先于吃。同一张牌多家能胡时只算最近的一家。
- 四家弃牌统一进牌桌中央的牌河：上=对家、下=你、左=上家、右=下家，亮框标出最新一张；被碰、杠、吃走的牌会从牌河移走。
- 支持暗杠、补杠、放杠；杠后从牌墙补一张。暂不处理抢杠。
- 胡牌按标准四组一对、七对、十三幺判断；不算番。
- 结算：自摸三家各付 2，出铳那家付 2；公杠每家 1，暗杠每家 2，放杠 3。**对局不收马。**
- 胡牌后赢家坐庄；流局庄家不变。

## 操作

- 点击牌墙上的牌加入手牌，点击手牌移除；「撤销一张」「清空」在牌架上方。
- 算番 / 筹码页顶部「玩法」切换鬼牌 / 花牌 / 都不加，相关选项会自动显示或隐藏；对局页的玩法在牌桌右上角单独选择。
- 13 张时会显示听牌，点听牌可直接补进手牌。
- 「筹码」页选庄家和胡法，点马牌摆进牌架，再填台面杠；点「记下这局」把净收支记进累计，赢家自动坐庄。
- 「随机试算」生成一把筹码账目，只用来试算，不是对局；下方「记账记录」可回看手动记下的每一把。
- 「对局」页先看庄家摇骰子；右侧「这把怎么开」会按实际点数拆成摇骰、数人、数墩、发牌、跳牌五步，并显示现在牌墙剩多少张，点「展开开局 6 步」查看，展开内容浮在侧栏上，不会把页面撑长。骰子数法和拿牌起点跟「拿牌」页共用，改一边另一边会同步。
- 对局右上角的「玩法」可选鬼牌红中 / 白板 / 发财，或无鬼无花；换玩法后点「重开本局」或等下一局生效。
- 桌面端（≥901px）六个分区统一按一屏排：收起重复页头、页脚和大标题，入门课堂的课程改成弹窗，番种表、番种账本、筹码账本等改成区域内部滚动；1280×720 及以上页面本身没有纵向滚动。窗口更窄时才回流成可滚动的手机布局。
- 对局页在这一屏里再压缩牌桌：牌河放进牌墙围出的中央空位，摸牌播报和弃牌都在桌心；右侧「这把怎么开」保持可展开但不撑长页面。
- 拿牌页右侧固定显示五步数法，底部提示「对局沿用这里的骰子数法与开门起点」；算番页的牌墙在宽屏把风牌、箭牌并成一行，番种速查改成两列名称 + 番数，悬停番种名仍能看到解释。
- 入门课堂顶部压成一条，七节课点开后用弹窗细读；弹窗可用 ×、Esc 或点背景关闭，关闭后焦点回到刚才点的那节课，不再把下面的课程列表撑长。
- 点手牌第一次是立牌，再点「打出」或再次点牌面出牌，点「取消」可以放回去。摸到的牌默认单独放在手牌最右边并标「摸」；点「整理手牌」把它并回顺子，再点一次又分开。
- 点「提示」或按 <kbd>H</kbd>，会按牌效率给出建议先打哪张，并列出备选牌和原因（孤张、边张、对子、搭子等）。
- 对局支持方向键移动手牌焦点、Enter 选牌 / 再按出牌、Esc 取消；切换分区或离开页面时，电脑回合自动暂停。
- 手机保留四方座位，手牌可左右滑动；牌河与牌墙示意图会压缩显示，选牌和取消后保留牌架位置。
- 轮到你吃碰杠胡时，手牌下方会出现对应按钮，点「过」放弃。胡牌或流局后点「再来一局」，赢家坐庄。
- 全部操作支持鼠标与触屏，窄屏会自动改成单列。

## 说明

番数与香港旧章、新章、跑马仔都有出入，本作按常见「旧章 / 三番起胡」整理；各桌规矩不同，开局前问一句「几番起胡、几番封顶、庄家加不加」最稳。筹码也一样：马怎么算、杠怎么付、封不封顶，开桌前先对一遍，页里的数字都能改。

对局是简化版：无花、不算番、不收马、暂不处理抢杠，同一张牌多家能胡只算最近的一家；电脑按牌效率出牌，不会做番型，会尽量留住鬼牌。牌墙示意按「四道墙、每面 17 墩、上下两层」画，跳牌剩下的下层牌按常见做法留到牌墙尾；不同牌桌对尾牌顺序可能有细微差别，以你们桌上的约定为准。
